# Headless-прогон китов

Игра открывается в iframe страницы-хоста (`host.html`) — ровно так, как её
встраивает бренд, — с фиксированным сидом. Боты (`bots.js`) живут внутри
страницы и работают на каждом шаге движка: эксперт обязан выиграть (ловит
непроходимость), новичок со случайными тапами обязан проиграть (ловит игру,
которая проходится сама). Покадрово проверяются инварианты: координаты и счёт
конечны, герой в канве и регулярно касается земли; за партию — ни ошибки
консоли, ни `pageerror`. Кнопки нажимаются настоящей мышью (тач-цели), ввод
высокой частоты (прыжок, ведение корзины) — событиями сцены.

```sh
cd tests/e2e
npm ci
npx playwright install chromium
npm test
```

Локально с глобальным Playwright: `NODE_PATH=$(npm root -g) node --test kits.e2e.js`.

Перекрытия для теста передаются через `window.ZV_TEST = { seed, params }` и
подмену `window.ZV_GAME` (архетип, приз) — см. `lib.js`. В обычной игре этих
объектов нет.

Что покрыто: runner (эксперт до порога, «Ещё раз», новичок), catch (эксперт и
неподвижная корзина), quiz (верные/неверные ответы, карточка приза и событие
`prize`), persona (исход из типов, детерминизм по сиду), wheel (три подачи,
без «Ещё раз»), platformer (эксперт по плану солвера проходит все уровни
`content/levels.json` с событием `progress` на каждый; новичок со случайным
вводом не выигрывает), сверка солвера с ботом (`tests/levelgen.js`: 8
сгенерированных проходимых уровней бот проходит одной партией, 5
непроходимых конструкций жадный бот не проходит; `levelsUnchecked` отключает
солвер при загрузке), novel (каждая концовка мышью по пути из `ZV.novel.paths`,
`progress` по главам, печать по буквам), quest (концовки, полка предметов
совпадает с графом, `meta.items` в `finish`), галерея (`tests/gallery.html`:
все киты шлют `ready`, «Заново» перезапускает, режим одного кита), битый
контент (экран ошибки и событие `error`).
