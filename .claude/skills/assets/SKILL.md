# Ассеты: заказ картинок

Стиль игр — пиксель-арт, его задаёт **платформа**, а не ты. Твоё дело —
описать ОБЪЕКТ и выбрать вид с размером. Герой и мир берутся из концепта
игры. Генерация стоит денег человека.

## Порядок железный

1. **Пока концепт не утверждён — заглушки.** Киты рисуют фигуры сами,
   играбельный прототип собирается без единой картинки. Баланс крутим на
   фигурах: это ходы, а не кредиты.
2. **Сначала ищи готовое** — `asset_search` по каталогу. Генерируй только то,
   чего в каталоге нет.
3. **Сначала герой**: `kind: "sprite"` — один статичный кадр.
4. **Покажи человеку, дождись «да».** Пока герой не утверждён, остальное не
   заказывай: он задаёт стиль всему набору.
5. **Из утверждённого героя — анимация**: `kind: "sheet"`, `source` = его URL.
6. Остальные спрайты — с `references` = URL героя, чтобы набор не развалился.
7. Ответ генерации подставляешь в `config.js` числами, а не на глаз.

## Инструмент asset_generate

| параметр | что кладём |
| --- | --- |
| `kind` | `sprite` герой/персонаж, `item` предмет, `icon` иконка, `ui` элемент интерфейса, `background` фон, `tile` тайл, `sheet` лист кадров анимации |
| `size` | `s` мелкое (предмет, иконка ~32), `m` обычное (герой ~64), `l` крупное (герой ~96, фон) |
| `action` | только для `sheet`: `walking`, `idle`, `jump`, `crouch`, `attack`, `destroy`, `custom` |
| `frames` | только для `sheet`: 4, 6, 8, 10, 12 или 16. Бег читается с 6–8 |
| `source` | только для `sheet`: URL уже сгенерированного героя — из него делаются кадры |
| `references` | URL героя для статичных спрайтов: держит единый стиль |
| `prompt` | ТОЛЬКО объект, по-английски |

Ответ приходит с `url`, `frame_width`, `frame_height`, `cols`, `rows` —
подставляй их, не подбирай.

## Промпт

Пишем **только сам объект, по-английски**.

- **Не пиши «pixel art»**, «8-bit», «retro» и прочий стиль — его ставит
  платформа, повтор только портит картинку.
- Фон называем плоским контрастным: `on a plain white background`.
- Цвета мира — хексами прямо в промпте:
  `courier in a red jacket, colors #E4002B #1A1A2E, on a plain white background`.
- **Один предмет — один запрос.** Никаких «сетка из шести иконок»: сетку
  нельзя разрезать, деньги уйдут впустую.
- Вид сбоку для бегущих, вид сверху/три четверти для падающих предметов —
  говори это словами: `side view`, `top down`.

Хромакей и `cols`/`rows` больше не нужны: прозрачность приходит настоящая,
сетку листа платформа возвращает в ответе.

## Пример: герой и его бег

```
1) kind: "sprite", size: "m",
   prompt: "side view courier character in a red jacket with a delivery bag,
            colors #E4002B #1A1A2E, on a plain white background"
   → показал человеку → утвердил
2) kind: "sheet", size: "m", action: "walking", frames: 8,
   source: "<url героя из шага 1>",
   prompt: "side view courier character running"
```
Прыжок и простой — такие же `sheet` с `action: "jump"` / `"idle"` и тем же
`source`. Один лист = одно действие, не смешивай.

## Подстановка в config.js

Ничего в коде кита править не нужно — он читает `ZV_GAME.assets` сам:

```js
assets: {
  hero: { url: "<url листа>", frameWidth: 64, frameHeight: 64, frames: 8, fps: 10 },
  items: {
    block:     { url: "<url>" },   // ключи смотри в README своего кита
    blockTall: { url: "<url>" }
  },
  background: { url: "<url>", tile: false }
}
```
- `frameWidth`/`frameHeight`/`frames` — из ответа (`frame_width`,
  `frame_height`, `cols`). Ошибёшься — кадры поедут.
- `fps`: персонаж 8–12, простой 4–6, взрыв 12–15. Дефолт Phaser 24 — не он.
- `tile: true` **только** если обе стороны фона 64/128/256. Иначе фон мылит.
- Одиночная картинка героя без анимации — `frames: 1`.

Цвета оформления игры (`config.theme`: `name`, `primary`, `secondary`,
`logoUrl`) картинками не дублируем — их ставит движок.

## Что НЕ генерировать

Логотипы (даёт человек), текст на картинке (подписи рисует движок), скриншоты
интерфейса, реальных людей и чужие бренды. Дым, свечение и тени — кодом
(`ZV.juice.shadow`, частицы), не картинкой.

## Экономия кредитов

- Один заказ = одна картинка, не «сгенерируй 6 вариантов, выберем».
- 5–10 картинок на игру — разумный потолок.
- Перегенерация — после конкретной правки человека («куртку красную»), а не
  «попробую ещё разок»; не больше 2–3 попыток, дальше меняй формулировку.
- Перед пачкой скажи вслух, сколько заказываешь, и дождись согласия.
