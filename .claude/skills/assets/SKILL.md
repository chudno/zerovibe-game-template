# Ассеты: сначала каталог, потом генерация

Генерация стоит денег человека. Порядок железный.

## Порядок

1. **Пока концепт не утверждён — заглушки.** Киты рисуют фигуры сами
   (`makeRect`/`makeCircle` в `preload`), играбельный прототип собирается без
   единой картинки. Баланс крутим на фигурах: это ходы, а не кредиты.
2. **`asset_search`** — каталог бесплатных картинок (CC0). Ищи по-английски и
   по существу: `crate`, `coin`, `runner character`, `city background`. Фон,
   платформы, монеты, иконки, UI — почти всегда закрываются каталогом.
3. **`asset_generate` — только фирменное**: маскот бренда, товар бренда,
   уникальный фон кампании. 5–10 картинок на игру, не больше.
4. Показал человеку → он утвердил → подставил URL в `config.js`.

## Стилевой паспорт

**Первый утверждённый ассет — референс для всех следующих.** Как только человек
одобрил, например, героя:
- запиши в `docs/brief.md` (раздел «Палитра») его URL и 1–2 фразы стиля:
  «плоский вектор, толстый контур 4px, без градиентов, палитра #E4002B/#101014»;
- каждую следующую генерацию делай с `references: ["<url героя>"]` и повторяй
  ту же формулу стиля в промпте.
Без этого набор развалится: половина картинок будет мультяшной, половина
реалистичной — и это первое, что заметит бренд.

Формула промпта: `<что> , <стиль из паспорта>, вид сбоку/сверху, целиком в
кадре, сплошной фон #00FF00, без теней и градиентов`.

## Хромакей

Прозрачности у генератора нет — фон вырезается по цвету.
- `chroma: "green"` — по умолчанию.
- `chroma: "magenta"` — если в самом объекте есть зелёный (курьер в зелёной
  форме, листья, трава, зелёный товар). Иначе объект прорежется дырами.
- `chroma: "none"` — фоны и картинки, которые лежат прямоугольником; иконки/UI
  в векторе (они приходят SVG, ключ прозрачности не нужен).

## Спрайт-листы

`kind: "sheet"` + `cols`/`rows`. Правила, иначе лист не режется:
- **Один персонаж на лист.** Не смешивай героя и врага.
- **Одна поза/действие на лист**: бег отдельно, прыжок отдельно. 4–6 кадров
  достаточно.
- Сетка ровная (`cols×rows`, например 4×1 или 3×2), кадр в кадре по центру,
  между кадрами ничего не пересекается.
- В промпте явно: «равномерная сетка cols×rows, один кадр = одна фаза движения,
  персонаж одного размера в каждом кадре, сплошной фон #00FF00».
- `frame_width/height` бери **из ответа генерации** и подставляй в
  `this.load.spritesheet` — не угадывай.

## Что НЕ генерировать

Хромакей не вытягивает полупрозрачное: **дым, туман, стекло, вода, тени,
свечение, огонь с мягкими краями, размытие в движении**. Такие эффекты —
кодом (частицы, тонирование, альфа-твины) или из каталога. Тень под героем —
тёмный овал с прозрачностью в коде, не картинкой.

Не генерируй: логотипы (лого бренда даёт человек), текст на картинке (модель
пишет с ошибками — подписи рисуй текстом движка), скриншоты интерфейса,
реальных людей и чужие бренды.

## Подстановка в кит

Меняешь `preload` кита: строку заглушки — на загрузку по ссылке файла проекта.
Ключи текстур в README кита (`hero`, `block`, `basket`, `good`, `bad`).

```js
PlayScene.prototype.preload = function () {
  this.load.image("hero", "https://<ссылка на файл проекта>/hero.png");
  this.load.spritesheet("run", "https://<ссылка>/hero-run.png",
    { frameWidth: 128, frameHeight: 128 });   // размеры — из ответа генерации
  makeRect(this, "ground", 8, 8, 0x2a2f45);   // фигуру можно оставить
};
```
Файлы картинок в репозиторий (`static/assets/`) не клади — они живут в файлах
проекта. После замены сверь хитбокс: `body.setSize`
множится на масштаб спрайта, так что вместе с `setDisplaySize` коллизия выходит
больше рисунка — проще держать текстуру нужного размера. Ошибку загрузки лови
(`this.load.on("loaderror", …)`) и оставляй фигуру — пустой экран хуже
прямоугольника.

## Экономия кредитов

- Каталог → генерация, никогда наоборот.
- Один заказ = одна картинка. Не «сгенерируй 6 вариантов, выберем».
- Разрешение `512` для спрайтов; `1K` только для фона.
- Перегенерация — после конкретной правки от человека («сделай куртку красной»),
  а не «попробую ещё раз».
- Перед пачкой генераций скажи вслух, сколько картинок и примерно сколько это
  кредитов, и дождись согласия.
- Провал генерации денег не стоит, но повторяй не больше 2–3 раз: если не
  выходит — меняй формулировку или бери из каталога.
