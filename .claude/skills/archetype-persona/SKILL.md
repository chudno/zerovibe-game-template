# «Какой ты» (persona): доводка кита

Файл `game/kits/persona/kit.js` — код не трогаем. Всё содержимое — в
`content/persona.json`, баланс — в `game/config.js` → `params`. Картинок не
нужно. Формат и валидатор — `game/kits/persona/README.md` и `game/content.js`.

## Что собрать под бриф

1. **Типы (2–8).** Каждый — `id` (латиница), `title` ≤ 40 («Спринтер»),
   `text` ≤ 240 (2 короткие фразы «про тебя», тон бренда), при желании `prize`
   (`title`, `code`, `text`, `button`, `url`). Типы — это **продукты или
   персонажи бренда**: «какой ты кофе», «какой тариф твой». 3–4 типа — норма.
2. **Вопросы (5–8).** У каждого 2–4 ответа, у ответа `weights` — баллы типам.
   Простая схема: один ответ — один тип по 2 балла; смешанные ответы
   (`{a: 1, b: 1}`) — только там, где это осмысленно.
3. **Каждый тип обязан быть достижим**: получать баллы хотя бы за один ответ и
   реально выигрывать при какой-то комбинации. Валидатор ловит первое;
   второе проверь руками: пройди тест «за каждый тип».
4. **Приоритет при равенстве** — порядок типов в файле: первый выигрывает
   ничью. Поставь первым тот тип, который бренду выгоднее показывать.
5. **Факты только из брифа**, ничего не сочиняй про продукт.

## Что крутить — `config.params`

`timePerQuestion` 0 (без таймера — тест не торопит; ставь 10–15 только если
бриф просит «на скорость»), `questionsPerRound` 0 (все), `shuffleQuestions`
и `shuffleAnswers` true. Больше крутить нечего — это тест, не аркада.

## Экран результата

Оболочка рисует «Ты — <title>», `text` типа и карточку его приза (код,
кнопка «Скопировать код» или «Забрать» → `url`). Счёт не показывается.
Наружу уходит `finish` с `outcome` = `id` типа и `prize` — партнёр видит
распределение типов (скилл `embed`).

## Грабли

- **Тип-«никогда»**: у типа нет ни одного ответа с баллами — валидатор
  красный. Или баллы есть, но всегда меньше конкурента — проверь прохождением.
- **Ответ без баллов** — валидатор красный; каждый ответ что-то значит.
- **Все ответы по 1 баллу разным типам** → частые ничьи → всегда первый тип.
  Дай «сильные» ответы по 2–3 балла.
- Длина: вопрос ≤ 90 символов, ответ ≤ 40 — иначе не влезает в 360×640
  (валидатор режет по длине).
- Не подсвечивай «верный» ответ — его нет; кит подсвечивает выбранный.

## Как объяснить заказчику

«Это тест как в соцсетях: пять вопросов — и человек узнаёт, какой он
<продукт/персонаж>. Каждому результату можно дать свой промокод. Правильных
ответов нет, поэтому проигравших тоже нет — доходят до конца все».

## Готово, когда

Прошёл тест так, чтобы выпал КАЖДЫЙ тип; тексты не обрезаны; у каждого типа,
где обещан приз, карточка показана; `node --test tests game` зелёный.
Дальше — `ready-checklist`.
