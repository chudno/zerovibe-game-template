# Встраивание игры на сайт бренда

Игра — самостоятельная страница по своему адресу. На сайт бренда она ставится
рамкой `<iframe>`; сайт может слушать, что происходит в игре.

## Код вставки

```html
<iframe src="https://<хост-игры>/?embed=1" title="Игра"
  allow="autoplay; fullscreen"
  style="width:100%;max-width:420px;aspect-ratio:9/16;border:0;border-radius:16px"></iframe>
```
`?embed=1` — оболочка прячет кнопку «во весь экран» (внутри рамки она не
работает) и не пытается занять весь экран телефона. Готовый код с адресами dev
и prod человек берёт во вкладке «Встраивание» — не сочиняй адреса сам.

## События

Игра шлёт родителю (`shell.js`, `window.parent.postMessage(msg, "*")`):
```js
{source: "zv-game", type: "ready"}                     // страница загрузилась
{source: "zv-game", type: "start"}                     // игрок нажал «Играть»
{source: "zv-game", type: "finish", score, won, meta,  // конец раунда
  outcome?, prize?: {id, title, code}}                 // исход словом и приз, если есть
{source: "zv-game", type: "prize", action, code, url?} // игрок нажал «Скопировать код»/«Забрать»
{source: "zv-game", type: "error", message, details}   // битые данные игры (content/*.json)
```
`outcome` — исход не числом: тип в «какой ты», id приза в розыгрыше, позже
концовка новеллы. `prize` — что показала карточка приза (из `config.prize`
или из контента кита). По `prize` и `outcome` партнёр считает воронку и
выдаёт одноразовые коды.
Обратно сайт может прислать `{source: "zv-host", type: "restart"}` — игра
начнёт заново.

Слушатель на стороне сайта:
```js
window.addEventListener("message", (e) => {
  const m = e.data;
  if (!m || m.source !== "zv-game") return;
  if (m.type === "finish" && m.won) showPromo(m.score);
});
```

## Твоя часть

- `finish` шлёт **оболочка**: кит вызывает
  `ZV.finish(scene, {score, won, meta, text, outcome, prize})` (скилл
  `game-runtime`). `text` — подпись под числом на экране результата, наружу не
  уходит. Приз за победу задаётся в `config.prize`, вручную его в `finish`
  передают только киты с призом внутри (розыгрыш, «какой ты»).
- `won` — булево «приз заслужен» по порогу из брифа. `meta` — маленький объект
  под кампанию (например `{level: 3}`), не сваливай туда всё состояние.
- **Имена `zv-game` / `zv-host` не переименовывай** — на них уже написан
  слушатель на сайте бренда.
- Не шли события чаще раза в раунд: `finish` на каждый подобранный бонус
  завалит сайт заказчика.
- Не читай ничего у родителя (`parent.document`, cookie, localStorage) — игра
  живёт на отдельном адресе, это и не сработает, и не нужно.
- Промокод «зашивать в игру» нельзя, если он одноразовый: игра — публичная
  страница, код увидят все. Одноразовые коды выдаёт сайт бренда по событию
  `finish`; в игре — общий оффер из брифа.

## Как объяснить заказчику (простыми словами)

«Игра живёт по своей ссылке. На сайт её ставят рамкой — как ролик с видео:
разработчик сайта вставляет одну строчку, код я дам во вкладке „Встраивание“.
Игра сама подстраивается под ширину блока.

Сайт может узнать результат: когда партия кончилась, игра сообщает счёт и
выиграл ли человек приз. По этому сигналу сайт показывает промокод, открывает
форму или считает статистику. Если промокоды одноразовые — их выдаёт ваш сайт
в этот момент, внутрь игры их зашивать нельзя, иначе код увидят все.

Ссылок две: рабочая — пока делаем и правим, и боевая — после публикации;
боевую можно повесить на ваш домен».

Не рассказывай про iframe, postMessage и события — только если человек сам
технический и спрашивает.
