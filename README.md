# Шаблон HTML-игры 2D

Заготовка мобильной игры-одностраничника: портретная канва 360×640, пиксельный
рендер, движок Phaser локальной копией, три готовых архетипа на заглушках. Игра
запускается и проходится сразу после клонирования — дальше меняются настройки,
картинки и правила, а не каркас.

## Запуск

```sh
go run ./cmd/server      # http://localhost:8080
go test ./...            # проверки шаблона (см. ниже)
```

Порт меняется переменной `PORT`, каталог статики — `STATIC_DIR` (локально
файлы читаются с диска, поэтому правку видно после перезагрузки страницы).

В проде та же статика отдаётся серверлесс-функцией: точка входа `Handler` в
`handler.go`, содержимое `static/` вшито в бинарь через `//go:embed`.

## Структура

```
handler.go              вход функции: событие → http.Handler
assets.go               //go:embed каталога static/
cmd/server/main.go      локальный сервер (в функцию не едет)
internal/ycf/           адаптер события функции ↔ net/http
internal/static/        раздача: тип по расширению, кэш, 404
static/index.html       оболочка страницы
static/game/config.js   НАСТРОЙКИ ИГРЫ: название, архетип, бренд, картинки
static/game/shell.js    экраны, мобильный контур, события встраивания
static/game/main.js     выбор кита по archetype
static/game/kits/*/     киты архетипов: runner, catch, quiz (+ README)
static/assets/          только заглушки; настоящие картинки — по ссылке
static/vendor/          Phaser 3.90.0 (MIT, LICENSE-phaser в корне)
```

## С чего начать

1. `static/game/config.js` — название, `archetype` (`runner` | `catch` |
   `quiz`), цвета бренда, секция `assets`.
2. `static/game/kits/<archetype>/README.md` — что крутить в этом ките:
   скорости, частота спавна, пороги победы, список вопросов.
3. Картинки — по ссылкам в `config.assets`, а не в репозитории (см. ниже).

## Как заменить заглушки на картинки

Код кита править не нужно: киты читают `config.assets` сами, а пока там пусто —
рисуют фигуры и всё равно играются.

```js
assets: {
  hero: { url: "<ссылка>", frameWidth: 64, frameHeight: 64, frames: 8, fps: 10 },
  items: { block: { url: "<ссылка>" } },   // ключи — в README кита
  background: { url: "<ссылка>", tile: false }
}
```

- `frameWidth`/`frameHeight`/`frames` берутся из ответа генерации, не на глаз;
- файлы картинок в репозиторий не кладём — они живут в файлах проекта;
- `tile: true` только если обе стороны фона 64/128/256 (степень двойки), иначе
  WebGL сглаживает текстуру вопреки пиксельному режиму;
- ошибка загрузки не ломает игру: кит остаётся на заглушке.

## Пиксель-арт

Игры пиксельные, и это накладывает жёсткие правила:

- канва 360×640, картинки рисуются 1:1 и ставятся масштабом 1;
- **дробный `setScale` запрещён** — он рвёт пиксельную сетку внутри спрайта;
  сплющивание и растяжение делает `ZV.juice` подменой кадра и сдвигом на целые
  пиксели, а не твином масштаба;
- `tileSprite` — только на текстуре со стороной 64/128/256;
- текст — через `ZV.ui.text` (моноширинный шрифт + `resolution` под экран);
- `image-rendering: pixelated` в `style.css` — без этой строки финальный
  CSS-апскейл размоет идеальные пиксели, остальные флаги не помогут.

## Мобильный контур

Задан в `shell.js` и `style.css`, переизобретать не нужно: дизайн-канва
360×640 портрет, `Scale.FIT` + `CENTER_BOTH` + `autoRound`, тап по `pointerup`,
разблокировка звука первым касанием на экране «Играть», тач-цели от 24
логических px (≈48 css), `touch-action: none`, `viewport-fit=cover`.

## Встраивание на сайт

```html
<iframe src="https://<хост>/?embed=1" title="Игра" allow="autoplay; fullscreen"
  style="width:100%;max-width:420px;aspect-ratio:9/16;border:0;border-radius:16px"></iframe>
```

`?embed=1` прячет кнопку «Во весь экран». Игра шлёт родителю:

```js
{ source: "zv-game", type: "ready" }                     // страница загрузилась
{ source: "zv-game", type: "start" }                     // игрок начал раунд
{ source: "zv-game", type: "finish", score, won, meta }  // раунд кончился
```

Обратно родитель может попросить перезапуск:

```js
iframe.contentWindow.postMessage({ source: "zv-host", type: "restart" }, "*");
```

Пример слушателя:

```js
addEventListener("message", (e) => {
  if (!e.data || e.data.source !== "zv-game") return;
  if (e.data.type === "finish") console.log("очки:", e.data.score, e.data.won);
});
```

## Что проверяют тесты

`go test ./...` не даёт выложить сломанную игру:

- каждая ссылка в html/css/js указывает на существующий файл, внешних адресов
  в статике нет;
- весь код игры парсится (синтаксическая ошибка в ките ловится до публикации);
- `config.js` исполняется, а его `archetype` соответствует существующему киту;
- функция отдаёт оболочку с контейнером игры, движок как JS, картинку как
  `image/png` в base64, неизвестный путь как 404;
- в статике нет имени платформы (игра уезжает на сайт заказчика).

Игровой баланс тесты не проверяют — это делает человек с телефона.
