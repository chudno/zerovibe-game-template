# Кит «Ловилка» (catch)

Корзина внизу ездит за пальцем, сверху сыплются предметы: хорошие ловим,
плохие пропускаем. Раунд ограничен по времени, промахи считаются.

## Что крутить

Объект `S` в начале `kit.js`:

| Поле | Что делает |
| --- | --- |
| `duration` | длительность раунда, мс |
| `fallStart` / `fallMax` | скорость падения и её потолок |
| `fallStep` | ускорение за каждый пойманный предмет |
| `spawnStart` / `spawnMin` / `spawnStep` | частота появления предметов |
| `badChance` | доля «плохих» предметов (0…1) |
| `goodPoints` / `badPenalty` | очки за хороший и штраф за плохой |
| `misses` | сколько хороших можно уронить до конца раунда |

Высота корзины — `BASKET_Y`; порог победы — в `finish` (сейчас 20 очков
и дожить до конца времени).

## Ассеты

| Ключ | Что это | Размер заглушки |
| --- | --- | --- |
| `basket` | корзина игрока | 180×70 |
| `good` | «хороший» предмет | круг Ø44 |
| `bad` | «плохой» предмет | круг Ø44 |

Замена заглушек на файлы проекта:

```js
PlayScene.prototype.preload = function () {
  this.load.image("basket", "https://<ссылка>/basket.png");
  this.load.image("good", "https://<ссылка>/apple.png");
  this.load.image("bad", "https://<ссылка>/bomb.png");
};
```

**Тело подставляй только через `ZV.sprite.apply`** — `setTexture` сбрасывает
тело под размер нового кадра, и корзина начинает ловить воздух:

```js
ZV.sprite.apply(this.basket, { texture: "basket", bodyW: 240, bodyH: 100, offsetY: 20 });
```
Числа тела — в `BASKET_BODY` и `ITEM_BODY` в начале `kit.js`, меняй их вместе
с картинкой. У корзины якорь по низу (`origin 0.5, 1`), у предметов — по
центру (`origin: false` в вызове), иначе круги «поедут» вверх.

Если предметов должно быть несколько видов, заведите массив ключей и в `spawn`
выбирайте случайный: `scene.items.create(x, -60, Phaser.Utils.Array.GetRandom(keys))`.

## Быстрые предметы

Физика игры идёт фиксированным шагом 1/60 (`fixedStep` в оболочке), поэтому
на просевших кадрах предмет не «телепортируется» мимо корзины. Сверх того в
`update` работает `sweptCatch`: он ловит предмет по отрезку, пройденному за
кадр. Поднимая `fallMax` выше 820, оба механизма оставь на месте.
