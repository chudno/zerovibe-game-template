# Кит «Викторина» (quiz)

Вопрос и четыре ответа, на каждый вопрос таймер. Верный ответ даёт очки плюс
бонус за оставшиеся секунды; чем дальше, тем меньше времени.

## Вопросы

Массив `QUESTIONS` в начале `kit.js`. Формат записи:

```js
{ q: "Текст вопроса", answers: ["Первый", "Второй", "Третий", "Четвёртый"], correct: 2 }
```

`correct` — индекс верного ответа, нумерация с нуля. Ответов может быть от двух
до четырёх: лишние кнопки прячутся сами. Порядок вопросов перемешивается на
каждый раунд (`shuffle`).

## Что крутить

| Поле `S` | Что делает |
| --- | --- |
| `timeStart` / `timeMin` | секунд на первый вопрос и нижняя граница |
| `timeStep` | на сколько сокращается таймер с каждым вопросом |
| `points` | очки за верный ответ |
| `bonusPerSec` | бонус за каждую оставшуюся секунду |
| `passScore` | порог победы |

## Ассеты

Кит текстовый, картинки не нужны. Если к вопросу нужна иллюстрация — добавьте
в запись поле `image` с ключом текстуры, загрузите её в `preload`
(`this.load.image(key, url)`) и покажите в `ask`:

```js
if (item.image) scene.pic.setTexture(item.image).setVisible(true);
else scene.pic.setVisible(false);
```

(объект `scene.pic` создайте в `create` через `scene.add.image(180, 240, "")`
— канва 360×640). Текст рисуйте только через `ZV.ui.text`: там пиксельный
шрифт и `resolution` под экран, обычный `add.text` даст мыло.
