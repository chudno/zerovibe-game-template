# Кит «Бегун» (runner)

Герой бежит на месте, дорожка едет навстречу, тап — прыжок. Раунд кончается,
когда герой врезался; счёт — число пройденных препятствий.

## Что крутить

Объект `S` в начале `kit.js`:

| Поле | Что делает |
| --- | --- |
| `gravity` | притяжение; больше — падение резче, прыжок «злее» |
| `jump` | сила прыжка (высота) |
| `speedStart` / `speedMax` | скорость препятствий в начале и потолок |
| `speedStep` | прибавка скорости за каждое пройденное препятствие |
| `spawnStart` / `spawnMin` | пауза между препятствиями и её нижняя граница |
| `spawnStep` | на сколько пауза сокращается с каждым препятствием |
| `lives` | сколько столкновений переживает герой |

Порог победы (`won`) — в функции `finish`: сейчас 15 препятствий.
Верх дорожки — константа `GROUND_Y` (канва 720×1280, портрет).

## Главное правило подстановки картинок

**После смены картинки герой обязан стоять на земле.** Любая смена текстуры
или анимации идёт только через `ZV.sprite.apply` — он один переприменяет тело
после `setTexture`/`play` (эти вызовы Phaser сбрасывают тело под размер кадра)
и держит якорь по низу ног (`origin 0.5, 1`), чтобы точка опоры не уезжала.

```js
ZV.sprite.apply(this.hero, {
  texture: "hero",   // или anim: "run"
  bodyW: 64, bodyH: 100,   // тело в единицах ТЕКСТУРЫ, не экрана
  scale: 1                 // необязательно
});
```
Прямой `hero.setTexture(...)` или `hero.anims.play(...)` в обход хелпера —
это «герой висит в воздухе» или «проваливается»; так провалилась первая игра.
После правки проверь в консоли: `ZV.game.scene.getScene('zv-play').hero.body.blocked.down`
должно быть `true`, когда герой на земле.

## Ассеты

Заглушки рисуются в `preload`. Ключи текстур:

| Ключ | Что это | Размер заглушки |
| --- | --- | --- |
| `hero` | герой, спрайт-лист на 2 кадра | 84×110 на кадр |
| `block` | низкое препятствие | 70×72 |
| `blockTall` | высокое препятствие | 70×132 |

Пол рисует оболочка (`ZV.floor`): видна полоска 28 px, а тело уходит вниз на
`ZV.FLOOR_DEPTH` — иначе быстро падающий герой пролетает сквозь него.

### Спрайт-лист героя

`frameWidth`/`frameHeight` бери **из ответа генерации**, не угадывай:

```js
PlayScene.prototype.preload = function () {
  this.load.spritesheet("hero", "https://<ссылка на файл проекта>/hero.png",
    { frameWidth: 96, frameHeight: 128 });
  this.load.image("block", "https://<ссылка>/block.png");
};
```

Потом поправь `HERO_BODY` в начале `kit.js` под новую картинку (тело чуть
уже картинки — 70–80 % ширины кадра, высота почти во весь кадр) и, если
кадров больше двух, диапазон в `makeAnims`:

```js
frames: scene.anims.generateFrameNumbers("hero", { start: 0, end: 5 })
```

Одиночная картинка вместо листа — тоже работает: `load.image` и
`ZV.sprite.apply(hero, { texture: "hero", bodyW: …, bodyH: … })` без `anim`.

## Анимация и «сок»

Анимации `run` / `jump` / `idle` заведены в `makeAnims` — с ними кит живой
сразу, изобретать их не нужно. Темп бега привязан к скорости мира в
`updateAnim`: `frameRate = clamp(speed / 40, 6, 16)`. Делишь на большее число —
ноги мельтешат медленнее; границы держи в этих пределах, иначе бег
рассинхронится со скоростью дорожки.

Оболочка даёт готовые приёмы (`ZV.juice`), кит их уже использует:
- `squash(scene, obj, 0.18, 80)` — сплющивание на приземлении;
- `stretch(...)` — растяжение на взлёте;
- `shadow(scene, obj, groundY, w)` — овал под ногами, зови `zvFollow()` в `update`;
- `dust(scene, x, y, color)` — 3 пылинки на приземлении.

Сплющивание меняет только масштаб спрайта; хитбокс при этом не «дышит» —
`ZV.sprite` пересчитывает тело с учётом масштаба.

## Проверка

`go test ./...`, затем `go run ./cmd/server` и открыть `/`: герой стоит на
дорожке, ноги перебирают, прыжок с приземлением даёт сплющивание и пыль,
консоль без ошибок.
