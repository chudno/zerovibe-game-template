# Кит «Бегун» (runner)

Герой бежит на месте, дорожка едет навстречу, тап — прыжок. Раунд кончается,
когда герой врезался; счёт — число пройденных препятствий.

## Что крутить

Объект `S` в начале `kit.js`:

| Поле | Что делает |
| --- | --- |
| `gravity` | притяжение; больше — падение резче, прыжок «злее» |
| `jump` | сила прыжка (высота) |
| `speedStart` / `speedMax` | скорость препятствий в начале и потолок |
| `speedStep` | прибавка скорости за каждое пройденное препятствие |
| `spawnStart` / `spawnMin` | пауза между препятствиями и её нижняя граница |
| `spawnStep` | на сколько пауза сокращается с каждым препятствием |
| `lives` | сколько столкновений переживает герой |

Порог победы (`won`) — в функции `finish`: сейчас 15 препятствий.
Высота дорожки — константа `GROUND_Y` (канва 720×1280, портрет).

## Ассеты

Заглушки рисуются функцией `makeRect` прямо в `preload`. Ключи текстур:

| Ключ | Что это | Размер заглушки |
| --- | --- | --- |
| `hero` | герой | 84×110 |
| `block` | препятствие | 76×96 (высокое — 76×180) |
| `ground` | полоса пола (не видна) | растягивается |

Чтобы поставить настоящую картинку, замените строку заглушки на загрузку по
ссылке файла проекта:

```js
PlayScene.prototype.preload = function () {
  this.load.image("hero", "https://<ссылка на файл проекта>/hero.png");
  this.load.image("block", "https://<ссылка на файл проекта>/block.png");
  makeRect(this, "ground", 8, 8, 0x2a2f45); // пол оставьте фигурой
};
```

Размер спрайта подгоняется `setDisplaySize`, коллизия — `body.setSize`; если
картинка другой пропорции, поправьте оба вызова в `spawn` и создание героя.
Для анимации бега грузите спрайт-лист:
`this.load.spritesheet("hero", url, { frameWidth: 84, frameHeight: 110 })`.
