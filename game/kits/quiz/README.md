# Кит «Викторина» (quiz)

Вопрос и до четырёх ответов, на каждый вопрос таймер. Верный ответ даёт очки
плюс бонус за оставшиеся секунды; чем дальше, тем меньше времени. Картинок не
нужно — кит текстовый.

## Вопросы — `content/quiz.json`

```json
{
  "questions": [
    { "q": "Текст вопроса", "answers": ["Первый", "Второй", "Третий", "Четвёртый"], "correct": 2 }
  ]
}
```

`correct` — индекс верного ответа, нумерация с нуля. Ответов от двух до
четырёх, лишние кнопки прячутся сами. Вопрос ≤ 90 символов, ответ ≤ 40 —
иначе не влезает в портрет 360×640. Порядок вопросов перемешивается на каждый
раунд (`ZV.random`, партия повторяется по `?seed=`).

Файл проверяется до публикации (`node --test tests game`) и при старте игры:
битый формат показывает список ошибок на экране вместо белой страницы.

## Что крутить — `config.params`

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `timeStart` / `timeMin` | 15 / 6 | секунд на первый вопрос и нижняя граница |
| `timeStep` | 1 | на сколько сокращается таймер с каждым вопросом |
| `points` | 10 | очки за верный ответ |
| `bonusPerSec` | 1 | бонус за каждую оставшуюся секунду |
| `passScore` | 30 | порог победы (максимум ≈ вопросов × (points + timeStart × bonusPerSec)) |
| `questionsPerRound` | 0 | сколько вопросов показать за раунд; 0 — все из файла |
| `shuffleAnswers` | false | мешать варианты (индекс верного пересчитывается сам) |

Приз за победу — `config.prize` (карточка с промокодом на экране результата).

## Ассеты

Не нужны. Иллюстрация к вопросу — поле `image` в записи вопроса и картинка
через `this.load.image` в `preload` кита: показывайте её в `ask`, текст —
только через `ZV.ui.text`.
