# Кит «Найди предмет» (hidden)

На фоне интерьера спрятаны предметы, внизу **полка** с тем, что ещё осталось
найти, сверху таймер. **Тап по предмету** — найден: он улетает на полку, очки
начисляются тем щедрее, чем быстрее нашёл. Среди спрятанного едут
**отвлечения** (`decoys`) — предметов, которых на полке нет: тап по ним стоит
времени (`decoyPenaltyMs`). Долго без находок — появляется подсказка:
пульсирующее кольцо вокруг одного из оставшихся.

Партия — `rounds` расстановок подряд, каждая со своим набором предметов.
Победа — найти всё во всех раундах до конца времени; поражение — время вышло.

**Координаты целей кит не проставляет руками.** Расстановку считает
`game/hidden.js`: предметы не налезают друг на друга, держат `minDistance`,
целиком лежат в области поля и повторяются при том же `?seed=`. Не влезло —
партия не стартует молча: на экран уходит число, сколько предметов на поле
поместится.

## Что крутить

Баланс — в `game/config.js`, секция `params`; `DEFAULTS` в начале `kit.js` —
значения по умолчанию (`ZV.params` их сливает, неизвестный ключ —
предупреждение в консоли).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `duration` | 40000 | время на всю партию, мс |
| `rounds` | 2 | сколько расстановок подряд |
| `targets` | 5 | сколько предметов прячется в раунде (они же на полке) |
| `decoys` | 2 | предметы-отвлечения: искать не надо, тап штрафуется временем |
| `hintMs` | 8000 | столько без находок — и появляется подсказка |
| `size` | 40 | сторона предмета, px (тач-цель всё равно не меньше 24) |
| `minDistance` | 56 | минимальное расстояние между центрами предметов |
| `hitPoints` | 10 | очки за находку |
| `speedBonusMax` | 10 | добавка за быструю находку (тает линейно к `hintMs`) |
| `decoyPenaltyMs` | 3000 | штраф времени за тап по отвлечению, мс |
| `passScore` | 0 | очков для победы; 0 — победа = найдено всё во всех раундах |

```js
params: { duration: 60000, rounds: 3, targets: 6, decoys: 3 }
```

**`targets + decoys` ограничены полем.** Поле поиска — 344×300 px, при `size`
40 и `minDistance` 56 туда влезает 20 предметов. Просишь больше —
`node --test tests game` краснеет строкой «влезает N предметов, а просят M»:
уменьшай `targets`/`decoys` или `minDistance`, а не потолок в `game/hidden.js`.

## Данные — `content/hidden.json`

```json
{
  "items": [
    { "id": "keys", "title": "Ключи", "icon": "keys" },
    { "id": "phone", "title": "Телефон", "icon": "phone" }
  ]
}
```

- `items` — от 4 до 40 предметов, `id` уникальны.
- `title` — подпись на полке: одна строка около 76 px (9 знаков кеглем 1).
  «Перчатка» — уже предел.
- `icon` — ключ картинки в `config.assets.items`, латиница/цифры/`-`/`_`.
  Не задан — берётся `id`.

Предметов в файле должно хватать на всю расстановку: `targets + decoys` штук
без повторов (две одинаковые подписи на полке не дают понять, какую из них уже
нашли). Валидатор (`validateHidden` в `game/content.js`) ругается словами, если
предметов меньше, подпись не влезает на полку, `id` повторяется или
расстановка при заданных `size`/`minDistance` на поле не помещается.

## Ассеты

| Ключ в `config.assets` | Что это | Размер заглушки |
| --- | --- | --- |
| `items.<icon>` | предмет: ключ равен `icon` (или `id`) из `content/hidden.json` | 40×40 |
| `background` | фон-интерьер, на котором прячутся предметы | нет |

```js
assets: {
  items: { keys: { url: "<ссылка>" }, phone: { url: "<ссылка>" } },
  background: { url: "<ссылка>", tile: false }
}
```

Без картинок кит рисует **заглушки разной формы** (квадрат, столбик, полоса,
крест, уголок, рамка), а не разноцветные квадраты: предмет должен читаться
силуэтом. Фон-заглушка — крупные пиксельные «пятна» интерьера и половицы:
на пустом фоне предметы видно сразу, и игры не получается.

Картинку предмета рисуй ровно `size`×`size` и ставь масштабом 1 — кит
применяет её через `ZV.sprite.apply`. Фон с `tile: true` обязан быть
64/128/256 по обеим сторонам.

## Payload

```js
ZV.finish(scene, {
  score, won, text: "очков",
  meta: { archetype: "hidden", rounds, found, decoyTaps, misses,
          bestFindMs, hints }
});
```

`ZV.progress` уходит в конце каждого раунда:
`{ step, total: rounds, meta: { score, found, cleared } }`.

## Что делает механику интересной

- **Полка — это список задач.** Видно, что осталось, и найденное не исчезает,
  а гаснет: прогресс читается без цифры.
- **Бонус за скорость.** Находка сразу даёт заметно больше, чем находка через
  восемь секунд — поиск становится соревнованием с собой, а не «рано или
  поздно найду».
- **Отвлечения вместо жизней.** Тап наугад по всему экрану не запрещён, он
  просто стоит времени. Наказание временем ощущается справедливее, чем
  отобранная жизнь, и не выкидывает из партии.
- **Подсказка приходит сама.** Игрок, который честно всё осмотрел, не упирается
  в стену: через `hintMs` кольцо покажет, где искать. Даром она не даётся —
  бонус за скорость к этому моменту уже стаял.
- **Фон решает всё.** Предметы обязаны лежать среди похожего мусора. Чистый
  фон делает игру пустой, рябой — нечестной; ориентир — крупные пятна
  интерьера, как у заглушки.

## Для автопрогона

- `window.__zvBot.hidden()` → `{ round, left, spots: [{id, x, y, size, decoy}],
  shelf, hintOn, hintAt, score, found, decoyTaps, leftMs, over }` — оставшиеся
  цели с координатами: тест тапает по ним настоящей мышью.
- `__zvBot.start("hidden", "expert")` — тапает оставшиеся цели раз в ~300 мс,
  отвлечения не трогает; `"novice"` тапает наугад по полю и обязан не успеть.
- Инварианты бота: счёт неотрицателен, координаты предметов — числа внутри
  канвы, `tl.pending() < 50`.
