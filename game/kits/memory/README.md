# Кит «Память-пары» (memory)

Карточки лежат рубашкой вверх. Тап открывает карточку, две одинаковые
остаются открытыми, разные — закрываются обратно на то же место. Партия
кончается, когда собраны все пары раскладов (победа) или кончились ходы
(поражение). Расклады — `content/memory.json`; сколько карточек на поле, автор
не задаёт: их ровно `2 · pairs`.

Ход тратится на **пару**, а не на тап: открыл две — минус ход. Первые
`freeMistakes` промахов раунда ход не тратят, а в начале раунда все карточки
на `previewMs` показываются открытыми — проиграть в первые секунды нельзя.

## Данные — `content/memory.json`

```json
{
  "rounds": [
    { "name": "Разминка", "hint": "Найди одинаковые", "pairs": 4 },
    { "name": "Смена", "pairs": 6, "moves": 16 },
    { "name": "Финал", "pairs": 8, "moves": 22 }
  ],
  "cards": [
    { "id": "box", "title": "Коробка", "icon": "box", "color": "#4f7cff" },
    { "id": "stamp", "title": "Печать" }
  ]
}
```

| Поле | Что это |
| --- | --- |
| `rounds` | от 1 до 10 раскладов подряд; каждый — своё поле |
| `rounds[].name` | заголовок раунда над полем (до 2 строк) |
| `rounds[].hint` | одна фраза под ним, необязательно |
| `rounds[].pairs` | сколько пар в раскладе, целое 2..12; карточек будет вдвое больше |
| `rounds[].moves` | лимит ходов на раунд; не меньше `2 · pairs + 2`, иначе раунд непроходим |
| `cards` | словарь видов карточек, 2..24; из него берутся первые `pairs` видов |
| `cards[].id` | латиница/цифры/`-`/`_` до 32, уникален |
| `cards[].title` | подпись на лицевой стороне: до 2 строк по ширине ячейки (~9 знаков при 8 парах, ~6 при 12 — ячейка тем уже, чем больше пар); у двух карточек не должна совпадать |
| `cards[].icon` | ключ картинки из `config.assets.items`, необязательно |
| `cards[].color` | `#rrggbb` лицевой стороны; без него цвет берётся из палитры по `id` |

Валидатор считает поле настоящей сеткой и настоящими метриками шрифта:
«8 пар = 16 карточек не влезают», «12 ходов на 8 пар — партия непроходима,
нужно минимум 18», «подпись «Коробка» уже у cards[0] — одинаковые карточки не
различить». Правится содержимое, не код.

## Что крутить — `config.params`

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `peekMs` | 800 | сколько несовпавшая пара остаётся открытой |
| `openMs` | 140 | «переворот»: карточка на кадр становится узкой полосой |
| `matchMs` | 320 | пауза после второй карточки до сравнения — успеть увидеть, что открылось |
| `previewMs` | 1200 | подглядка в начале раунда: все карточки открыты; 0 — без неё |
| `moves` | 0 | лимит ходов на раунд; 0 — без лимита (`rounds[].moves` перебивает). Проверяется тем же порогом `2 · pairs + 2` |
| `timeLimit` | 0 | лимит времени на раунд, мс; 0 — без таймера |
| `mistakePenalty` | 0 | очков за промах; 0 — без наказания (ход уже потрачен) |
| `pairPoints` | 10 | очков за найденную пару |
| `streakBonus` | 5 | добавка за пару сразу после пары (серия) |
| `roundBonus` | 25 | очков за пройденный раунд |
| `freeMistakes` | 2 | первые промахи раунда не тратят ход |
| `showTitles` | true | подписи на лицевой стороне (без иконок — единственный способ различать) |
| `passRounds` | 0 | сколько раундов достаточно для победы; 0 — все. Больше числа раскладов — зажимается по нему |

## Ассеты

| Ключ в `config.assets` | Что это | Размер |
| --- | --- | --- |
| `items.<icon>` | картинка вида карточки по ключу `icon` из `content/memory.json` | до размера ячейки; крупнее — масштаб 1/n |
| `items.back` | рубашка карточки; без неё рисуется тёмная заливка со знаком «?» | до размера ячейки; крупнее — масштаб 1/n |
| `background` | фон поля | — |

Пусто — заглушки: рубашка тёмная со знаком «?», лицо — цвет карточки с
подписью. Игра полностью проходится без единой картинки.

## Что уходит наружу

`progress` — на каждый раунд (`step`/`total`, в `meta` — `pairs`, `moves`,
`mistakes`, `cleared`). `finish`:

```js
{ score: 87, won: true, text: "очков",
  meta: { archetype: "memory", rounds: 3, pairs: 8, mistakes: 5,
          moves: 21, bestStreak: 3, record: true } }
```

`won` — пройдено не меньше `passRounds` раскладов (0 — все). Рекорд лежит в
`ZV.save` под именем `memory` и на проходимость не влияет: партия всегда
начинается с нуля. Если игра брендированная (скилл `branding`) — приз за
победу в `config.prize`.

## Что делает механику интересной

- **«Я же помнил!»** — главное чувство здесь: открыл вторую карточку почти
  наугад, и она совпала. Ради него и сделана подглядка `previewMs`: без неё
  первые шесть ходов — лотерея, и человек решает, что игра про удачу.
- **Ход за пару, а не за тап.** Счётчик ходов виден всегда, промах не
  наказывает дважды, при промахе карточки задерживаются `peekMs` — этого
  хватает, чтобы запомнить, и в этом вся честность механики.
- **Нарастание — ходами, не размером поля.** `moves` подбирается так, чтобы
  идеальная игра проходила с запасом четверти, а невнимательная — нет.
- **Темп.** Тап во время анимации не теряется, а буферизуется: третья
  карточка откроется сразу, как только пара закроется. Без этого игра
  ощущается тормозной, хотя всё считается верно.
- **Конец виден.** Последняя пара бьёт тряской сильнее прочих, счётчик ходов
  краснеет за три хода до конца.

## Для автопрогона

`window.__zvBot.memory()` отдаёт состояние сцены:
`{ round, rounds, open, found, pairs, moves, busy, over, cells }`, где
`cells` — координаты ячеек для настоящих тапов мышью, а `busy` — занят ли
таймлайн. Бот не спит `peekMs`, а ждёт `busy === false` — тайминги в тестах
не участвуют.
