# Кит «Три в ряд» (match3)

Поле фишек под счётом. **Обмен двух соседних фишек** собирает линию от трёх
подряд по горизонтали или вертикали: собранное осыпается, верхние фишки падают
вниз, сверху досыпаются новые — и если при этом снова сложилась линия, идёт
**каскад** с растущим множителем. Ходы ограничены, побеждает тот, кто набрал
`targetScore` за `moves` ходов.

Ввод двойной и равноправный: **тап по фишке → тап по соседней** (выбранная
обведена контуром; второй тап по ней же снимает выбор) и **свайп** в сторону
соседа. Обмен, который ничего не собирает, — фишки качнулись и вернулись; по
умолчанию он тоже тратит ход (`wrongCostsMove`). Кончились ходы — поражение,
набрал цель — победа. Если на поле не осталось ни одного хода, кит сам говорит
«перемешиваю» и тасует **те же** фишки: состав партии не меняется, ход на это
не тратится.

Вся логика — в чистом `game/match3.js`: раздача без готовых троек и всегда с
ходом, поиск всех совпадений (включая пересечения), список ходов, каскад,
перемешивание, очки и прогон партии для валидатора. Кит только рисует поле и
принимает ввод.

## Что крутить

Баланс — в `game/config.js`, секция `params`; `DEFAULTS` в начале `kit.js` —
значения по умолчанию (`ZV.params` их сливает, неизвестный ключ — предупреждение
в консоли).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `cols` | 6 | столбцов поля (4..8; на 360 px шесть даёт ячейку 52 px) |
| `rows` | 7 | строк поля (4..9) |
| `kinds` | 5 | видов фишек (3..7), не больше, чем описано в `content/match3.json` |
| `moves` | 20 | ходов на партию — главная ручка длины |
| `targetScore` | 600 | очков для победы — главная ручка сложности |
| `base` | 10 | очков за каждую собранную фишку |
| `cascadeStep` | 1 | прибавка к множителю за каждый шаг каскада |
| `lineBonus` | 20 | очков за каждую фишку сверх трёх в одной линии |
| `swipeMin` | 16 | сдвиг пальца, с которого жест считается свайпом, px |
| `wrongCostsMove` | true | неудачный обмен тоже тратит ход |
| `fallMs` | 60 | шаг падения фишки на одну клетку, мс |
| `clearMs` | 140 | пауза «собралось» перед осыпанием, мс |
| `wobbleMs` | 90 | качок фишек на неудачном обмене, мс |

```js
params: { cols: 6, rows: 7, kinds: 5, moves: 25, targetScore: 900 }
```

Очки за один сбор: `фишек × base + (фишек − 3) × lineBonus`, всё это умножается
на `1 + номер каскада × cascadeStep`. Отсюда и ощущение: тройка — привычные 30,
четвёрка — уже 60, а тройка вторым шагом каскада — тоже 60. Каскад
единственное место, где счёт растёт кратно, поэтому `cascadeStep` трогай
осторожно.

**`targetScore` и `moves` проверяются валидатором прогоном игры.**
`game/match3.js` играет партию лучшим ходом на пяти фиксированных сидах и
случайными тычками — и говорит числами, если цель либо не набирается даже
лучшей игрой, либо набирается случайными тычками. Правь `config.params` по
этому числу; порог человеческой руки в ядре не трогай.

## Данные — `content/match3.json`

```json
{
  "goal": { "title": "Собрано", "text": "Собирай по три и больше подряд" },
  "kinds": [
    { "id": "leaf",  "title": "Лист",   "color": "#2e9e5b", "shape": "circle" },
    { "id": "drop",  "title": "Капля",  "color": "#38bdf8", "shape": "diamond" },
    { "id": "sun",   "title": "Солнце", "color": "#d9a100", "shape": "square" },
    { "id": "berry", "title": "Ягода",  "color": "#ff5f6d", "shape": "cross" },
    { "id": "stone", "title": "Камень", "color": "#9b59b6", "shape": "bar" }
  ]
}
```

- `goal.title` — подпись цели в HUD (рядом печатается число `targetScore`),
  `goal.text` — строка-пояснение.
- `kinds` — от 3 до 7 видов фишек. `id` — латиница, `title` — как вид
  называется словами, `color` — `#rrggbb`, `shape` — форма заглушки:
  `circle`, `diamond`, `square`, `cross`, `bar`, `triangle`, `ring`.
- `icon` (необязательно) — ключ картинки в `config.assets.items`.

Валидатор (`validateMatch3` в `game/content.js`) ругается словами, если видов
меньше трёх или больше семи, `id`, подпись, цвет **или форма** повторяются
(две фишки одной формы игрок путает даже при разных цветах), `params.kinds`
больше словаря, либо цель не согласована с числом ходов.

## Ассеты

Картинки описываются в `config.assets`, код кита править не нужно. Пусто —
рисуются заглушки разной формы, и игра всё равно проходится.

| Ключ в `config.assets` | Что это | Размер заглушки |
| --- | --- | --- |
| `items.<icon>` | фишка: ключ равен `icon` вида (по умолчанию `k1`…`k7`) | сторона ячейки минус 8 (при `cols` 6 — 44×44) |
| `background` | фон | нет |

```js
assets: {
  items: {
    leaf: { url: "<ссылка>" },
    drop: { url: "<ссылка>" }
  },
  background: { url: "<ссылка>", tile: false }
}
```

Фишку рисуй квадратной и под сторону ячейки: кит ставит её через
`ZV.sprite.apply` и при необходимости прореживает масштабом `1/n` — дробного
масштаба здесь нет. Фон с `tile: true` обязан быть 64/128/256 по обеим
сторонам.

## Payload

```js
ZV.finish(scene, {
  score, won, text: "очков",
  meta: { archetype: "match3", moves, movesLeft, cleared, bestCascade,
          shuffles, target, record }
});
```

`cleared` — сколько фишек собрано за партию, `bestCascade` — самый длинный
каскад, `shuffles` — сколько раз поле пришлось перемешать.

## Что делает механику интересной

- **Каскад.** Единственный источник кратного счёта: собрал внизу — верх
  осыпался сам и сложился ещё раз. Без множителя (`cascadeStep: 0`) игра
  превращается в равномерную прополку.
- **Ход как валюта.** Ходов мало и они считаются вслух: за три хода до конца
  счётчик краснеет. Неограниченные ходы убивают всякий выбор.
- **Цена ошибки.** `wrongCostsMove` делает «ткнуть наугад» настоящим решением.
  Выключай его только для совсем малышовой аудитории.
- **Линия длиннее трёх.** `lineBonus` учит искать четвёрку вместо первой
  попавшейся тройки — то есть смотреть на поле, а не на первую линию.
- **Формы, а не цвета.** Пять оттенков кружков на телефоне сливаются; разная
  форма читается краем глаза и на ходу.
- **Тупик не наказывает.** Нет ходов — кит перемешивает те же фишки и говорит
  об этом. Партия, которая кончается «сама», ощущается как поломка.

## Для автопрогона

- `window.__zvBot.match3()` → `{ cols, rows, cells, layout: [{i,x,y,w,h}],
  score, movesLeft, movesUsed, cleared, shuffles, bestCascade, picked, busy,
  over }` — поле и координаты клеток.
- `__zvBot.start("match3", "expert")` — каждый ход берёт `ZV_MATCH3.best()` по
  текущему полю и отыгрывает его тап-тапом; `"novice"` меняет случайную пару
  соседей и обязан проиграть.
- Инварианты бота: вне каскада поле полное и без готовых совпадений, фишек на
  сцене столько же, сколько клеток, счёт неотрицателен, `tl.pending() < 60`.
