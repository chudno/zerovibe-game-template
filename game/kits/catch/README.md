# Кит «Ловилка» (catch)

Корзина внизу ездит за пальцем, сверху сыплются предметы: хорошие ловим,
плохие пропускаем. Раунд ограничен по времени, промахи считаются.

## Что крутить

Баланс — в `game/config.js`, секция `params`; `DEFAULTS` в начале `kit.js` —
значения по умолчанию (`ZV.params` их сливает, неизвестный ключ — предупреждение
в консоли).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `duration` | 45000 | длительность раунда, мс |
| `fallStart` / `fallMax` | 160 / 410 | скорость падения и её потолок, px/с |
| `fallStep` | 6 | ускорение за каждый пойманный предмет |
| `spawnStart` / `spawnMin` / `spawnStep` | 900 / 380 / 20 | частота появления предметов, мс |
| `badChance` | 0.28 | доля «плохих» предметов (0…1) |
| `goodPoints` / `badPenalty` | 1 / 2 | очки за хороший и штраф за плохой |
| `misses` | 5 | сколько хороших можно уронить до конца раунда |
| `passScore` | 20 | очков для победы, если дожил до конца времени |
| `maxRepeat` | 2 | сколько раз подряд может выпасть один и тот же вид предмета (0 — без ограничения) |

```js
params: { duration: 30000, badChance: 0.2 }
```

Высота корзины — `BASKET_Y` (канва 360×640). Где появится предмет — `ZV.random`
(сид из `?seed=`), какой именно вид — `ZV.pool` (`game/pool.js`, см. «Веса и
антиповтор» ниже). `Math.random` запрещён тестом.

## Ассеты

Картинки описываются в `config.assets`, код кита править не нужно. Пусто —
рисуются заглушки, и игра всё равно проходится.

| Ключ в `config.assets` | Что это | Размер заглушки |
| --- | --- | --- |
| `items.basket` | корзина игрока | 90×32 |
| `items.good`, `items.good2`, `items.good3` | «хорошие» предметы | 22×22 |
| `items.bad`, `items.bad2`, `items.bad3` | «плохие» предметы | 22×22 |
| `background` | фон | нет |

```js
assets: {
  items: {
    basket: { url: "<ссылка>", body: { x: 3, y: 4, w: 84, h: 28 } },
    good:   { url: "<ссылка>", weight: 3 },
    good2:  { url: "<ссылка>", weight: 1 },
    bad:    { url: "<ссылка>" }
  },
  background: { url: "<ссылка>", tile: false }
}
```

### Веса и антиповтор

Виды предметов держит `ZV.pool` (`game/pool.js`). Какая категория выпадет —
`good` или `bad` — решает `badChance`: доля вредного остаётся ручкой баланса
и от числа картинок не зависит. А какой именно вид внутри категории — это
`weight` рядом с картинкой (по умолчанию 1): `weight: 3` против `weight: 1`
значит «втрое чаще»; `weight: 0` — вид не выпадет никогда, картинку можно
оставить в конфиге и выключить одним числом. Сверху лежит антиповтор
`maxRepeat` (2): один и тот же вид не выпадет третий раз подряд, если есть из
чего выбрать. Это только про вид, не про категорию — три хороших предмета
подряд по-прежнему нормальны.

Ни одной картинки в категории не заказано (или она не загрузилась) — играем
одной заглушкой на категорию, партия проходится как есть. Если же в категории
все веса выставлены в 0, кит вернёт первому виду вес 1: иначе выбирать было бы
не из чего и предметы просто перестали бы сыпаться.

### Тело предмета

Тело считает `ZV.sprite.apply` по непрозрачной области кадра — руками в ките
ничего задавать не нужно. Точные числа, если они есть, кладутся рядом с
картинкой: `body: { x, y, w, h }` — непрозрачная область в пикселях кадра,
левый верх. Эти числа приходят из ответа `asset_generate`, подбирать их на
глаз не надо.

У корзины якорь по низу, у предметов — по центру (`origin: false` в вызове),
иначе они «поедут» вверх. Меняешь текстуру в коде — **только через
`ZV.sprite.apply`**: `setTexture` сбрасывает тело под размер нового кадра,
и корзина начинает ловить воздух.

Фон с `tile: true` обязан быть 64/128/256 по обеим сторонам, иначе кит
поставит его обычной картинкой с целым масштабом. Картинки не масштабируются
дробно: это пиксель-арт.

## Быстрые предметы

Физика игры идёт фиксированным шагом 1/60 (`fixedStep` в оболочке), поэтому
на просевших кадрах предмет не «телепортируется» мимо корзины. Сверх того в
`update` работает `sweptCatch`: он ловит предмет по отрезку, пройденному за
кадр. При `fallMax` 410 и просадке до 10 fps предмет проходит 41 px за кадр,
а корзина высотой 35 px — поднимая `fallMax`, оба механизма оставь на месте.

## Что делает механику интересной

- Корзина должна слушаться пальца мгновенно: любая задержка читается как
  «игра меня подвела», а не «я промахнулся».
- Темп задаёт `spawnStart` → `spawnMin`: начинать надо так, чтобы поймать было
  легко, и уплотнять поток постепенно, не рывком.
- Честность: плохой предмет должен быть виден заранее и отличаться силуэтом,
  а не только цветом — иначе штраф ощущается как обман.
- Рост сложности идёт двумя ручками сразу (`fallStep` и `spawnStep`);
  разгонять только скорость скучно, только частоту — душно.
- «Ещё раз» держится на близком проигрыше: `misses` и `passScore` подбирай так,
  чтобы типичный конец был в паре очков от победы.
