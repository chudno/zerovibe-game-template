# Кит «Ловилка» (catch)

Корзина внизу ездит за пальцем, сверху сыплются предметы: хорошие ловим,
плохие пропускаем. Раунд ограничен по времени, промахи считаются.

## Что крутить

Баланс — в `game/config.js`, секция `params`; `DEFAULTS` в начале `kit.js` —
значения по умолчанию (`ZV.params` их сливает, неизвестный ключ — предупреждение
в консоли).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `duration` | 45000 | длительность раунда, мс |
| `fallStart` / `fallMax` | 160 / 410 | скорость падения и её потолок, px/с |
| `fallStep` | 6 | ускорение за каждый пойманный предмет |
| `spawnStart` / `spawnMin` / `spawnStep` | 900 / 380 / 20 | частота появления предметов, мс |
| `badChance` | 0.28 | доля «плохих» предметов (0…1) |
| `goodPoints` / `badPenalty` | 1 / 2 | очки за хороший и штраф за плохой |
| `misses` | 5 | сколько хороших можно уронить до конца раунда |
| `passScore` | 20 | очков для победы, если дожил до конца времени |

```js
params: { duration: 30000, badChance: 0.2 }
```

Высота корзины — `BASKET_Y` (канва 360×640). Где и какой предмет появится —
`ZV.random` (сид из `?seed=`), `Math.random` запрещён тестом.

## Ассеты

Картинки описываются в `config.assets`, код кита править не нужно. Пусто —
рисуются заглушки, и игра всё равно проходится.

| Ключ в `config.assets` | Что это | Размер заглушки |
| --- | --- | --- |
| `items.basket` | корзина игрока | 90×32 |
| `items.good` | «хороший» предмет | 22×22 |
| `items.bad` | «плохой» предмет | 22×22 |
| `background` | фон | нет |

```js
assets: {
  items: {
    basket: { url: "<ссылка>" },
    good:   { url: "<ссылка>" },
    bad:    { url: "<ссылка>" }
  },
  background: { url: "<ссылка>", tile: false }
}
```

Числа тела — в `BASKET_BODY` и `ITEM_BODY` в начале `kit.js`, меняй их вместе
с картинкой (тело 70–80 % кадра, иначе корзина «ловит» прозрачными полями).
У корзины якорь по низу, у предметов — по центру (`origin: false` в вызове),
иначе они «поедут» вверх. Меняешь текстуру в коде — **только через
`ZV.sprite.apply`**: `setTexture` сбрасывает тело под размер нового кадра,
и корзина начинает ловить воздух.

Несколько видов предметов — массив ключей и случайный выбор в `spawn`:
`scene.items.create(x, -30, ZV.random.pick(keys))`.

Фон с `tile: true` обязан быть 64/128/256 по обеим сторонам, иначе кит
поставит его обычной картинкой с целым масштабом. Картинки не масштабируются
дробно: это пиксель-арт.

## Быстрые предметы

Физика игры идёт фиксированным шагом 1/60 (`fixedStep` в оболочке), поэтому
на просевших кадрах предмет не «телепортируется» мимо корзины. Сверх того в
`update` работает `sweptCatch`: он ловит предмет по отрезку, пройденному за
кадр. При `fallMax` 410 и просадке до 10 fps предмет проходит 41 px за кадр,
а корзина высотой 35 px — поднимая `fallMax`, оба механизма оставь на месте.
