# Кит «Розыгрыш» (wheel)

Одно действие — и приз по весам. Три подачи одной механики, выбираются
параметром `presentation`:

| Подача | Что видит игрок |
| --- | --- |
| `wheel` | колесо секторов, подсветка бежит по кругу и замирает на призе |
| `scratch` | скретч-карта: палец стирает серый слой, под ним приз и код |
| `lootbox` | коробка: тап, тряска, крышка открывается, приз всплывает |

Колесо не вращается картинкой: произвольный угол мылит пиксель-арт и текст.
Бегущая подсветка по неподвижным секторам читается так же и остаётся ровной.

## Призы — `content/wheel.json`

```json
{
  "items": [
    { "id": "d10", "title": "Скидка 10%", "weight": 25, "code": "SPIN10",
      "text": "На любой заказ до конца месяца", "color": "#2e9e5b" }
  ]
}
```

- от 2 до 12 призов; `title` ≤ 24 символов (сектор узкий), `code` ≤ 32;
- `weight` — вес выпадения, вероятность = вес / сумма весов. **Веса
  подтверждает человек**: это шанс выигрыша в акции бренда;
- `weight: 0` — сектор виден, но не выпадает никогда (для красоты колеса);
  призов с ненулевым весом должно быть минимум два;
- `color` необязателен — иначе палитра по кругу.

Распределение проверено тестом (`game/random.test.js`): на 10 000 розыгрышей
доли сходятся к весам, нулевой вес не выпадает.

## Что крутить — `config.params`

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `presentation` | "wheel" | подача: "wheel", "scratch" или "lootbox" |
| `spinMs` | 3200 | длительность розыгрыша: бег подсветки, тряска коробки, мс |
| `scratchPercent` | 55 | сколько процентов карты стереть, чтобы она открылась |
| `replay` | false | показывать ли «Ещё раз» на результате (розыгрыш обычно один) |

## Ассеты

Колесо и скретч рисуются фигурами. Коробке можно дать картинки:
`config.assets.items.box` (закрытая) и `items.boxOpen` (открытая), обе одного
размера с якорем по низу; пусто — заглушка 120×100.

## Что уходит наружу

`finish` несёт `outcome` (id приза) и `prize` (`id`, `title`, `code`) — партнёр
учитывает выданные коды. Повторный розыгрыш возможен только перезагрузкой
страницы или `replay: true`; лимит попыток на игрока — на стороне сайта бренда
(игра статическая, у неё нет сервера).
