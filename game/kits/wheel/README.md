# Кит «Розыгрыш» (wheel)

Одно действие — и выпадает исход по весам. Три подачи одной механики,
выбираются параметром `presentation`:

| Подача | Что видит игрок |
| --- | --- |
| `wheel` | колесо секторов, подсветка бежит по кругу и замирает на исходе |
| `scratch` | скретч-карта: палец стирает серый слой, под ним результат и код |
| `lootbox` | коробка: тап, тряска, крышка открывается, находка всплывает |

Колесо не вращается картинкой: произвольный угол мылит пиксель-арт и текст.
Бегущая подсветка по неподвижным секторам читается так же и остаётся ровной.

## Исходы — `content/wheel.json`

```json
{
  "items": [
    { "id": "d10", "title": "Скидка 10%", "weight": 25, "code": "SPIN10",
      "text": "На любой заказ до конца месяца", "color": "#2e9e5b" }
  ]
}
```

- от 2 до 12 исходов; `title` должен влезать в сектор: 2 строки по ~9 знаков
  (при 9–12 секторах — по ~7), `code` — одна строка до 12 знаков (кегль 2) или
  25 (кегль 1); валидатор считает по метрикам шрифта;
- `weight` — вес выпадения, вероятность = вес / сумма весов. **Веса
  подтверждает человек**: это шанс выигрыша;
- `weight: 0` — сектор виден, но не выпадает никогда (для красоты колеса);
  исходов с ненулевым весом должно быть минимум два;
- `color` необязателен — иначе палитра по кругу.

Распределение проверено тестом (`game/random.test.js`): на 10 000 розыгрышей
доли сходятся к весам, нулевой вес не выпадает.

## Что крутить — `config.params`

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `presentation` | "wheel" | подача: "wheel", "scratch" или "lootbox" |
| `spinMs` | 3200 | длительность розыгрыша: бег подсветки, тряска коробки, мс |
| `scratchPercent` | 55 | сколько процентов карты стереть, чтобы она открылась |
| `replay` | false | показывать ли «Ещё раз» на результате (розыгрыш обычно один) |

## Ассеты

Колесо и скретч рисуются фигурами. Коробке можно дать картинки:
`config.assets.items.box` (закрытая) и `items.boxOpen` (открытая), обе одного
размера с якорем по низу; пусто — заглушка 120×100.

## Что делает механику интересной

- Ожидание дороже результата: подсветка должна замедляться и «почти» останавливаться
  не на том секторе — это единственный момент напряжения во всей механике.
- Честность на виду: все исходы показаны до броска, игрок сам видит, чего много,
  а чего мало.
- Результат читается мгновенно — крупная надпись и один цвет, без экрана с текстом.
- Промах тоже событие: пустой сектор должен быть оформлен, а не выглядеть ошибкой.
- «Ещё раз» включать осознанно: одна попытка держит ценность, бесконечные — убивают её.

## Что уходит наружу

`finish` несёт `outcome` (id исхода) и `prize` (`id`, `title`, `code`).
Если игра брендированная (скилл `.claude/skills/branding/SKILL.md`) — приз
описывается в `config.prize`, а выданные коды учитывает принимающая сторона.
Повторный розыгрыш возможен только перезагрузкой страницы или `replay: true`;
лимит попыток на игрока — на стороне сайта, где игра размещена (игра
статическая, у неё нет сервера).
