# Кит «Собери заказ» (sort)

По ленте слева направо едут предметы, внизу 2–4 корзины. **Тап по корзине**
отправляет туда текущий предмет — тот, что ближе всех к красной линии сброса.
Среди предметов едет **мусор** (`bin: "junk"`): его надо пропустить, не тапая
ничего. Верные подряд копят серию и множитель к очкам; неверная корзина
снимает жизнь, пропущенный обычный предмет — только рвёт серию.

Партия кончается по времени (`duration`) или по `targetItems`, а также когда
кончились жизни. Победа — набрать `passScore` (или разобрать `targetItems`).

## Что крутить

Баланс — в `game/config.js`, секция `params`; `DEFAULTS` в начале `kit.js` —
значения по умолчанию (`ZV.params` их сливает, неизвестный ключ — предупреждение
в консоли).

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `duration` | 45000 | длительность раунда, мс |
| `beltSpeed` | 90 | стартовая скорость ленты, px/с |
| `beltMax` | 190 | потолок скорости ленты |
| `beltStep` | 4 | прибавка скорости за каждый верно разобранный предмет |
| `spacing` | 150 | расстояние между предметами на ленте, px |
| `lives` | 3 | ошибок до конца раунда |
| `freeMistakes` | 2 | первые N ошибок не снимают жизнь |
| `hitPoints` | 10 | очки за верную корзину (умножаются на серию) |
| `junkPoints` | 5 | очки за верно пропущенный мусор |
| `missPenalty` | 0 | штраф очками за неверную корзину (0 — только жизнь) |
| `junkChance` | 0.12 | доля мусора в начале партии |
| `junkChanceMax` | 0.28 | доля мусора к концу партии |
| `streakStep` | 5 | сколько верных подряд дают +1 к множителю |
| `streakMax` | 3 | потолок множителя серии |
| `targetItems` | 0 | разобрать столько предметов для победы (0 — считать по `passScore`) |
| `passScore` | 150 | очков для победы |
| `showBinHint` | true | первые 5 предметов подписаны названием их корзины |

```js
params: { duration: 60000, passScore: 200, junkChance: 0.2 }
```

**`beltMax` и `spacing` менять с оглядкой на темп.** `game/sort.js` считает,
сколько миллисекунд человек видит предмет в полосе решения перед линией сброса
и какая пауза остаётся до следующего. Порог: не меньше 350 мс на любой
скорости от `beltSpeed` до `beltMax`, и пауза не короче 1,2 проезда предмета.
Нарушил — `node --test tests game` краснеет, а игра при старте показывает
экран ошибки с готовым числом («не больше 194»). Это не придирка: игра, в
которую нельзя успеть, ощущается сломанной, а не сложной.

## Данные — `content/sort.json`

```json
{
  "bins": [
    { "id": "cold", "title": "Холод", "color": "#38bdf8" },
    { "id": "hot",  "title": "Горячее", "color": "#ff5f6d" },
    { "id": "dry",  "title": "Сухое", "color": "#d9a100" }
  ],
  "items": [
    { "id": "ice",  "title": "Лёд",   "bin": "cold", "weight": 3, "icon": "ice" },
    { "id": "soup", "title": "Суп",   "bin": "hot",  "weight": 3 },
    { "id": "box",  "title": "Пустая коробка", "bin": "junk", "weight": 2 }
  ]
}
```

- `bins` — от 2 до 4 корзин. `id` — латиница (`junk` занят мусором), `title`
  печатается на корзине, `color` — `#rrggbb`, заливка корзины.
- `items` — от 4 до 40 предметов. `bin` — **ровно одна строка**: `id` корзины
  или `"junk"`. Предмет с двумя верными корзинами игрок не отличит от
  собственной ошибки, поэтому массив там запрещён валидатором.
- `weight` — вес в пуле (по умолчанию 1); 0 — предмет не выедет никогда.
- `icon` — ключ картинки, латиница/цифры/`-`/`_`.

Валидатор (`validateSort` в `game/content.js`) ругается словами, если корзин
меньше двух или больше четырёх, подпись не влезает, `id` повторяется, корзина
осталась без единого предмета с весом больше нуля, `bin` указывает на
несуществующую корзину, или мусор и `junkChance` разошлись (доля больше нуля,
а предметов `junk` нет — и наоборот).

## Ассеты

Картинки описываются в `config.assets`, код кита править не нужно. Пусто —
рисуются заглушки, и игра всё равно проходится.

| Ключ в `config.assets` | Что это | Размер заглушки |
| --- | --- | --- |
| `items.<icon>` | предмет: ключ равен `icon` (или `id`) из `content/sort.json` | 40×40 |
| `items.bin_<id>` | значок корзины: ключ `bin_` плюс `id` корзины | нет (только заливка) |
| `background` | фон | нет |

```js
assets: {
  items: {
    ice: { url: "<ссылка>" },
    soup: { url: "<ссылка>" },
    bin_cold: { url: "<ссылка>" }
  },
  background: { url: "<ссылка>", tile: false }
}
```

Предмет на заглушке **нейтрально-серый** (`#e6e8f0`) с подписью: цвет корзины
на предмете превратил бы игру в «тапай по цвету». Картинку предмета рисуй
40×40 и ставь масштабом 1 — кит применяет её через `ZV.sprite.apply`. Значок
корзины ложится поверх заливки `bin.color`, подпись съезжает под него.

Фон с `tile: true` обязан быть 64/128/256 по обеим сторонам, иначе кит
поставит его обычной картинкой с целым масштабом.

## Payload

```js
ZV.finish(scene, {
  score, won, text: "очков",
  meta: { archetype: "sort", sorted, mistakes, missed, junkPassed,
          bestStreak, topSpeed }
});
```

`ZV.progress` уходит каждые 10 обработанных предметов (разобранных, ошибочных,
пропущенных и мусорных вместе): `{ step, total, meta: { score, streak } }`.
`total` не нулевой только при заданном `targetItems`.

## Что делает механику интересной

- **Серия.** Пять верных подряд — множитель ×2, счёт начинает расти заметно,
  и цена ошибки становится ощутимой. Без множителя сортировка остаётся
  механической работой; `streakStep` и `streakMax` — главная ручка «о!».
- **Мусор.** Первый же мусорный предмет переучивает рефлекс «тапать всё» за
  один раз. Без мусора игра вырождается: тапай любую корзину подряд.
- **Категории читаются за 0,3 с.** «Холодное / горячее / сухое» человек
  различает мгновенно, «молочное / кисломолочное» — нет. Плохо различимые
  категории читаются как нечестность, а не как сложность.
- **Ошибиться страшно, не успеть — нет.** Жизнь снимается только за неверную
  корзину; уехавший предмет рвёт серию и всё. Это делает игру про точность, а
  не про долбёжку.
- **Нарастание тремя ручками.** `beltStep` разгоняет ленту, доля мусора растёт
  от `junkChance` к `junkChanceMax`, последние 10 секунд лента получает белую
  полосу и заметный рывок. Разгонять что-то одно — скучно.
- **Первые 10 секунд без наказания.** `freeMistakes` и медленный старт: игрок
  успевает понять корзины раньше, чем начинает терять жизни.

## Для автопрогона

- `window.__zvBot.sort()` → `{ current: {id, bin, x, y} | null, bins: [{id, x, y}],
  score, lives, streak, sorted, over }` — текущий предмет и координаты корзин.
- `__zvBot.start("sort", "expert")` — знает верную корзину, мусор пропускает;
  `"novice"` жмёт первую корзину всегда и обязан проиграть по жизням.
- Инварианты бота: предметов на ленте не больше 8, ни один не левее −64 px,
  счёт неотрицателен, `tl.pending() < 50`.
